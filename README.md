# GAUSS-SEIDEL-calculator
An interactive web application that uses the Gauss-Seidel iterative method to solve linear equation systems. Built using a Python backend and a lightweight Flask web framework, featuring an intuitive UI for quick mathematical computations and matrix inputs.

A lightweight, interactive web application built with **Python** and **Flask** designed to solve systems of linear equations using the iterative **Gauss-Seidel method**.

## 🚀 Features
* **Interactive UI:** Easily input matrix coefficients and constants.
* **Iterative Solver:** Computes solutions step-by-step using the Gauss-Seidel algorithm.
* **Custom Convergence:** Allows users to specify tolerance levels and maximum iterations.

## 🛠️ Tech Stack
* **Backend:** Python, Flask
* **Frontend:** HTML, CSS, JavaScript (or Bootstrap)

   ```bash
   git clone https://github.com
   ```
